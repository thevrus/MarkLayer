# Site notes

- **Marketing pages**: `apps/site` prerenders every content page to static HTML (`build.format: 'file'`, `trailingSlash: 'never'` — extensionless URLs like `/vs/markup-io`). The worker's `build` runs `embed:site`, copying `apps/site/dist` into its client asset output, so production serves those pages straight from the asset layer with no Worker invocation. `assets.run_worker_first` in `wrangler.jsonc` is load-bearing: only the listed dynamic paths hit Hono; setting it to `true` would route `/vs/*` into the proxy catch-all. Pages served from assets miss the Worker's HSTS middleware, so `apps/site/public/_headers` reapplies it, and `scripts/emit-headers.mjs` appends per-route `Cache-Control` from `src/data/routes.json`, which also derives the worker's dev proxy; `verify-build.mjs` fails a built page missing from that table. `apps/site` is also a workspace dep of the worker, which makes Turbo build it first. Every `ArticleLayout` page renders as a docs shell (sidebar from `docs-nav.ts`, article, outline); the layout renders its slot to a string so `outline()` can id every heading before printing it. Page gutter is `--gutter` (24px, 40px from `sm`), the landing's own, so the header and footer sit on the same x as `/`.
