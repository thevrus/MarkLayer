---
version: '0.11.0'
name: 'Say exactly what should change'
date: '2026-10-30'
title: 'MarkLayer 0.11.0: CSS Edits, In-Place Text Edits, Batch Send'
description: 'MarkLayer 0.11.0 lets you try CSS on an element, edit page text in place, draw inside an area, dictate notes and hold notes back to send them together.'
summary: >-
  A note can now carry the change itself: CSS you tried on the element, the text as it should read, or marks drawn on
  the part of the page that is wrong. Notes can be held back and sent together, and dictated instead of typed.
changes:
  - kind: new
    title: Try CSS on an inspected element
    text: >-
      With one element inspected, open its styles and change spacing, type, colour or size, and the page updates as you
      type. The note carries every edit as a from-and-to line, so an agent applies what you settled on instead of
      guessing. Closing the note puts the page back.
  - kind: new
    title: Edit the page's text where it is
    text: >-
      Double-click text with the selection or inspect tool and type the copy as it should read. It is saved as a
      suggested edit, so whoever picks it up sees the exact before and after.
  - kind: new
    title: Draw inside an area note
    text: >-
      An area note has its own pen, ellipse, rectangle and arrow, kept inside the box. The marks are drawn on the
      note's screenshot, so trackers and agents see them too.
  - kind: new
    title: Hold notes and send them together
    text: >-
      Switch on Batch in any note card and new notes stay on your screen until you press Send. Nobody else sees them
      before then, and you can edit or remove any of them from the pending list. Replies still go out at once.
  - kind: new
    title: Dictate a note
    text: >-
      A microphone button in the comment, area and inspect composers turns speech into text. Click to toggle it, or
      hold it and let go to stop. It appears in browsers with speech recognition built in, such as Chrome; Firefox
      does not have it.
  - kind: new
    title: Emoji reactions
    text: >-
      React to a comment or a reply from its card, or type ":" in the composer to complete an emoji the way "@"
      completes a name.
  - kind: new
    title: Review rooms for agents, with versions and polls
    text: >-
      An agent can open a review room on any URL through the MCP tools, and later builds of the same branch chain into
      versions with a switcher. It can ask reviewers to vote in a poll and keep a next-steps checklist at the top of
      the comments that ticks off as it works.
  - kind: new
    title: Password-protect a link
    text: >-
      A link's owner can set a password in its settings. Anyone opening the link, or an agent connecting to it, needs
      it, and changing it closes sessions already open.
  - kind: new
    title: Pin an intro video to a room
    text: >-
      Record a short video that sits above the comments and explains what you want reviewed. Re-recording keeps the
      older takes as versions.
  - kind: improved
    title: Inspect captures more of the element
    text: >-
      An inspect note now records the element's id, classes, text and key computed styles, and the React, Vue or
      Svelte component it belongs to. All of it reaches the agent prompt.
  - kind: improved
    title: Notes come with a screenshot and video notes with a transcript
    text: >-
      Each new pin attaches a cropped screenshot of where it was placed, which travels to issue trackers and webhooks.
      Video notes are transcribed, so they can be read and searched.
  - kind: improved
    title: Hover a highlight to open its card
    text: >-
      In the viewer, resting the pointer on a highlight opens its comment card. Links and text selection under the
      highlight still work.
  - kind: improved
    title: Undo only takes back your own marks
    text: >-
      Undo used to be able to remove a teammate's comment or a poll vote. It now only undoes what you made.
  - kind: improved
    title: A page that won't load opens with its notes
    text: >-
      When a page refuses to load in the viewer, "Open original site" now carries the room with it, so with the
      extension installed you land on the live page with the annotations on it.
---
