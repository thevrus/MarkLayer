description: 'MarkLayer 0.4.0 introduces the marklayer-mcp server so AI coding agents can work a room of annotations, plus the area tool, multi-inspect, quick grab and a share dialog.'
summary: >-
  Annotation stopped being something you only send to a person. The MCP server hands a room straight to a coding
  agent, which reads the comments, works through them and marks each one done while you watch it happen.
changes:
  - kind: new
    title: The MCP server
    text: >-
      One command connects Claude Code, Cursor or any MCP client to a room. The agent lists the annotations,
      acknowledges them, replies and resolves them, and every status change shows up live on your side of the page.
  - kind: new
    title: Area tool
    text: Drag a rectangle around a region and attach a note to it, for feedback that is about a block rather than a point.
  - kind: new
    title: Multi-inspect
    text: >-
      Pick several elements in one pass and hand the whole set over at once, instead of inspecting and pasting them
      one at a time.
  - kind: new
    title: Quick grab
    text: Hold Alt to capture an element without leaving the tool you are already using.
  - kind: new
    title: Share dialog
    text: One place to create the link, copy it, and see what the person opening it will get.
  - kind: new
    title: Settings panel
    text: Your display name, your colour and your tool preferences, in one sheet instead of scattered across the toolbar.
  - kind: new
    title: Measure in the web viewer
    text: >-
      The measure tool works on proxied pages too, so you get the same pixel numbers without installing the extension.
  - kind: improved
    title: Area and multi-inspect on the web
    text: Both new tools shipped in the web viewer at the same time as the extension, rather than a release behind it.
---

The MCP server is the piece that changes the shape of the work. Everything
before it made feedback easier to write; this makes it something another program
can pick up and act on without a human transcribing it into a ticket first.
