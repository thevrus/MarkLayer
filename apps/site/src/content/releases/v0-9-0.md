title: 'MarkLayer 0.9.0: Connect an Agent by URL, Extension Rooms'
description: 'MarkLayer 0.9.0 serves every share link as an MCP server, lets an agent read the page, leave notes and take a thread, and adds screenshots on comments.'
summary: >-
  Every share link is now an MCP server an agent connects to with one line, and the agent is a real participant: it
  reads the page, leaves its own notes and suggested edits, and picks up a thread the moment someone hands it over.
  Two people with the extension can also share one room, so a page only you can reach is no longer a dead end.
changes:
  - kind: new
    title: Connect an agent with a URL
    text: >-
      The share link's own address, with /mcp on the end, is a remote MCP server. Claude Code connects with one
      `claude mcp add` line and anything configured by file takes the same URL; nothing is installed. The npm package
      stays for clients that only run local servers, and the "Connect an AI agent" panel now leads with the URL.
  - kind: new
    title: Hand a thread to the agent
    text: >-
      An agent watching a room used to hear only new top-level notes, so a reply asking it to act reached nobody. It now
      wakes when a thread is assigned to it, when a reply @mentions it, or when anyone replies under a thread it already
      owns, and the reply that woke it travels with the event as the instruction.
  - kind: new
    title: Agents leave their own notes and suggest edits
    text: >-
      An agent can pin a comment of its own instead of only answering yours, and propose an exact text change that shows
      up as a diff you accept or reject. Both anchor to the element, so they stay put when the page reflows.
  - kind: new
    title: Agents can read the page
    text: >-
      Asked to review a page nobody had annotated yet, an agent had nothing to go on. It can now read the page's text
      and structure through the same fetch the viewer uses, in a shape that feeds straight into a suggested edit.
  - kind: new
    title: Screenshots on comments and replies
    text: >-
      A comment or a reply takes up to four images, from the file picker or pasted straight from the clipboard. An agent
      reading the thread gets them as image links it can open.
  - kind: new
    title: See who is in the room
    text: >-
      "2 online" counted people without saying who. Clicking it now lists everyone with a live status, plus the last few
      people who left, so "did I just miss them" has an answer.
  - kind: new
    title: Two people with the extension can share one room
    text: >-
      A share link only ever opened the web viewer, which has to load the page itself, so an internal staging site
      annotated fine and shared into nothing. The room travels now instead of the page: join one from the extension's
      settings and both of you mark up your own copy of the page together. Joining merges your existing marks into the
      room rather than replacing them.
  - kind: new
    title: Annotate from the right-click menu
    text: >-
      "Annotate this page" sits in the page's context menu, so the toolbar icon is no longer the only way in.
  - kind: new
    title: A tool fan on the collapsed toolbar
    text: >-
      Press and drag the collapsed toolbar button to fan the drawing tools out around it, then release on one. The fan
      turns to face open space, so it still fits with the toolbar pushed into a corner.
  - kind: new
    title: Send the link by email or the share sheet
    text: >-
      The share popover can mail the link to an address. Where the browser has a system share sheet, on most phones and
      Chromium desktops, that takes the slot instead and hands the link to whatever app you already use.
  - kind: improved
    title: Agents show up as themselves
    text: >-
      An agent appeared as its bare client id and a lowercase "c" where an avatar goes. Agents now show their product's
      name, mark and colour in the presence list and on everything they leave, and read "connected" rather than an idle
      time, since an agent sends no cursor to measure one by.
  - kind: improved
    title: A link you keep is kept
    text: >-
      Claiming a link put it on your dashboard but it was still deleted after 90 days without a visit, like an anonymous
      one. A claimed link is now exempt from that idle clock. An expiry you set on it still applies.
  - kind: improved
    title: Toasts wait for you, and links in comments are clickable
    text: >-
      A toast pauses its countdown while the pointer or keyboard focus is on it, so it cannot vanish mid-read. A bare
      URL in a comment renders as a link with a shortened label.
  - kind: fixed
    title: An agent keeps watching
    text: >-
      Nothing pushes a note to an idle agent; it has to keep calling watch, and agents were reading an empty result as
      "the reviewer is done". The tool now says plainly that it is a loop and an empty result only means the window
      ran out, and the window is short enough to finish inside a client's request timeout.
  - kind: fixed
    title: A short room id can no longer be opened live
    text: >-
      Old-style short share ids were already refused for saving, but strangers could still meet on one live. Every way
      into a room now refuses an id that is neither the current format nor an existing room.
---

The URL connection and the stdio package share one contract, so a reply that
wakes an agent on one wakes it on the other. A room connected over HTTP and the
same room connected through `npx` cannot behave differently depending on how
the agent happened to arrive.
