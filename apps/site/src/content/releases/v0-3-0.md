description: 'MarkLayer 0.3.0 adds the element inspector with React, Vue and Svelte component detection, a pixel measure tool, and a toolbar you can reorder.'
summary: >-
  Two tools that turn "this looks off" into something a developer can act on: what the element actually is, and how
  far it sits from the thing beside it.
changes:
  - kind: new
    title: Element inspector
    text: >-
      Point at anything and get a stable CSS selector plus an AI-ready Markdown snapshot of the element: its styles,
      its box, and the React, Vue or Svelte component that rendered it.
  - kind: new
    title: Measure
    text: Read an element's dimensions, and the edge-to-edge gap between any two elements, in pixels.
  - kind: new
    title: Rearrange the toolbar
    text: Drag the tools into the order you actually use them. The arrangement is remembered.
  - kind: improved
    title: No dead share links
    text: >-
      The share button hides on localhost, .local hostnames, 127.0.0.1 and non-web addresses, because the person
      opening your link could never have reached those anyway.
