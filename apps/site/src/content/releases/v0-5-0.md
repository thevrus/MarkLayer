date: '2026-08-29'
title: 'MarkLayer 0.5.0: Suggested Edits, Ruler Guides, Priorities'
description: 'MarkLayer 0.5.0 adds suggested copy edits on a text selection, synced ruler guides, priority levels and assignees on comments, and a Figma-matching keymap.'
summary: >-
  The largest release so far. A text selection can now carry the exact rewrite you want, ruler guides sync to everyone
  in the room like any other annotation, and every comment gets a priority and an owner.
changes:
  - kind: new
    title: Suggested edits
    text: >-
      Select some copy and propose the replacement wording. The popover, the pin card, the side panel and the Markdown
      export all show it as a before and after, and a coding agent reading the room applies your exact words instead of
      interpreting a description of them.
  - kind: new
    title: Ruler guides
    text: >-
      Pull guides out of the rulers to line elements up, then flip or delete them. They persist and reach every other
      person in the room, because a guide is an annotation like any other rather than a local overlay.
  - kind: new
    title: Priority levels
    text: Mark a comment, an area or a selection low, medium, high or urgent, and click the level to cycle it.
  - kind: new
    title: Assignees
    text: Give a comment thread an owner, so a review with four people in it still says who is picking each thing up.
  - kind: new
    title: The eraser reaches everything
    text: It deletes comments, areas, selections and inspected elements now, not only ink.
  - kind: new
    title: Hold Shift to constrain
    text: >-
      Shift snaps lines and arrows to 45 degrees and locks shapes to a square or a circle, on every drawing tool.
  - kind: new
    title: Voice and video controls
    text: Choose your camera, microphone and speaker from a device menu, and drag the call bubble anywhere on the page.
  - kind: new
    title: Zoom presets in the web viewer
    text: Auto, 50%, 75% and 100%, for reviewing a desktop layout on a laptop screen.
  - kind: new
    title: A public share API
    text: >-
      Create a share link over plain HTTP with no key and no account. It is described by an OpenAPI spec at
      /api/openapi.json, so an agent can find the endpoint without being told about it.
  - kind: improved
    title: Figma's keymap
    text: >-
      V, R, O, T, C, P, L and E pick tools, H is the hand and Shift+H the highlighter. If your hands already know
      Figma, they know MarkLayer.
  - kind: improved
    title: One design language
    text: The extension and the web app were both restyled in Geist, so the toolbar looks the same wherever you opened it.
  - kind: improved
    title: Anchors survive a resize
    text: >-
      An annotation reprojects by its target element's scale now, not only by its position, so it stays on the thing
      you pointed at when the layout reflows at a different width.
  - kind: improved
    title: Share links preview the annotations
    text: >-
      Paste a link into Slack, Linear or a message and the preview card now draws the actual marks on the page rather
      than a generic logo, so the person deciding whether to open it can already see what was flagged.
  - kind: improved
    title: The real retention window
    text: The viewer states the actual 90 days an annotation is kept, where it used to say "Never".
  - kind: improved
    title: Faster large captures
    text: Quick grab crops its screenshot in the background, so a high-resolution capture no longer stalls the page.
  - kind: fixed
    title: Overlay buried by the host page
    text: A page that applied a transform to its own body could push the toolbar behind its content. It stays on top.
  - kind: fixed
    title: Web annotations drifted
    text: >-
      Comments, selections and text made in the web viewer now bind to their element the way the extension's always
      did, so they hold their position when the page reflows.
  - kind: fixed
    title: Overlapping pins
    text: The pin you are hovering rises above its neighbours instead of hiding underneath one.
  - kind: fixed
    title: A bad edit could damage a room
    text: >-
      Every edit is validated before it is broadcast and stored, so one malformed operation can no longer corrupt a
      room for everyone in it.
---

Most of this release is about saying what you mean precisely enough that nobody
has to guess. A suggested edit is the clearest case: instead of a comment asking
for the heading to be shorter, you hand over the shorter heading.
