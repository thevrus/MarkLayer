## Where SureFeedback charges and MarkLayer doesn't

SureFeedback has no free plan. Cloud starts at $199 for the first year and $299 after that, which buys five sites and five mockups. The sixth client site moves you to Professional, $349 then $499. The self-hosted plugin is cheaper at $99 to $119 a year, though you also pay for the WordPress hosting it runs on and the time spent keeping it updated.

MarkLayer has no site count, mockup count or seat count. A share link is the whole unit and you can mint as many as you want. What you give up is the structure around them: organizations, workspaces, roles, and a dashboard listing every client's site.

## The script on the client's site

The practical difference is the script. SureFeedback works by putting its widget on the page. On WordPress that is a connector plugin; elsewhere you copy a script and paste it before the closing `</body>` tag. Once it's there, anyone with the access link can comment on the real site. The catch is that someone with deploy access has to add it.

MarkLayer fetches the page from its own server and overlays the canvas, so a public URL needs nothing at all. A page behind a password or a login needs the free browser extension, which annotates in the tab where you are already signed in. Neither route touches the site's code.

## Self-hosting means two different things here

SureFeedback's self-hosted plugin keeps every comment inside your own WordPress database. Its comparison page is plain about it: if feedback data must stay on your server, pick the plugin. For agencies under a client contract that says so, that settles it.

MarkLayer is Apache-2.0 open source, and you can run the whole thing on your own Cloudflare account. That is data ownership too, but on Cloudflare rather than inside WordPress. If your stack is already WordPress, SureFeedback's version is the shorter path.

## Private comments, approvals and branding are SureFeedback's

Three things SureFeedback sells have no MarkLayer counterpart. Internal-only comments let your team argue about the client's font choice where the client can't see it; MarkLayer has one channel per room. Page approvals give a client a formal sign-off button and a request-changes loop. And the self-hosted plugin is white label, so clients see your agency's name instead of SureFeedback's.

MarkLayer has an Approved status on each comment, which only a person can set, but nothing like a per-page sign-off with an audit trail.

## The agent on the other end

Both tools now talk to Claude, Cursor and other MCP clients. SureFeedback's server needs a Cloud account and an API key, and an agent with write access can create, update, resolve and delete comments. That is broad access, so the per-key read, write and delete scopes matter.

MarkLayer's is free and needs no key. Every share link is itself an MCP server, so `claude mcp add --transport http marklayer https://marklayer.app/s/<id>/mcp` is the whole setup. The agent watches the room live, acknowledges a thread so the reviewer sees it is in progress, resolves or dismisses it with a reason, and replies. It can leave its own comment pins and propose exact text replacements the reviewer accepts as a diff. It can never mark a thread approved.

## Live review versus client sign-off

SureFeedback is built around the agency handing a client a link and collecting comments and approvals over days. MarkLayer has that async mode too, but it also has the room: live cursors show who is looking where, and a peer-to-peer voice or video call runs in the same tab. Desktop, tablet and mobile widths sit side by side on one screen. SureFeedback doesn't advertise any of the three.

One limit runs the other way. MarkLayer is desktop only today, and a phone will tell you so. SureFeedback's plugin page says it works on any mobile device.

## Who should not switch from SureFeedback

WordPress agencies whose clients sign off page by page, who need a private back-channel, or who must keep feedback on their own server. Those are what SureFeedback is built for. Everyone else is choosing between $99 to $999 a year and a share link that costs nothing.
