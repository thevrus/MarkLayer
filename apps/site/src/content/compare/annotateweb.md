---

MarkLayer and AnnotateWeb solve the same problem the same way: paste a URL, mark up the live page, send a link, and nobody — sender or reviewer — installs anything or creates an account. If you are choosing between them, the install question is settled for both.

The difference is what survives the session. AnnotateWeb is built for a one-shot annotation and deletes it two minutes after you stop touching it; it is translated into eight languages and exports a PNG. MarkLayer is built for a review cycle: threaded comments with priority and status, multi-page projects in one share, 90-day retention, an MCP server that hands the feedback straight to an AI coding agent, and an Apache-2.0 codebase you can self-host. MarkLayer also ships an optional Chrome extension for the pages a proxy cannot reach — sites behind a login, and localhost.
