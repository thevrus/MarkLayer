# UI 规则（2026-11-11，所有 agent 必须遵守）

## 铁律

**UI 严格按原生/上游项目的来，不许自创样式。**

1. 配色、字号、间距、圆角、动效，一律从上游仓库 `origin`（https://github.com/thevrus/MarkLayer）现有实现里取，即 `packages/tokens`、各 `@theme`（`apps/worker/web/style.css`、`apps/extension/entrypoints/content/style.css`、`apps/site/src/styles/global.css`）及现有组件用到的值。
2. 组件里不许写死新的 hex、rgb、oklch 或像素值。已有 token 直接用（`text-ui`、`tracking-ui`、`leading-body`、`text-ml-accent-fg` 等）。
3. 上游没有的东西不要发明。确实需要新值，先在 `docs/dispatch-2026-11-11.md` 里写清「要什么、为什么、上游哪里找不到」，等确认，不要自行加。
4. 功能不增不减，只动布局和视觉。

## 验收

- `bun run check` 与 `bun test` 通过。
- 新增或改动的样式里没有新的 hex、rgb、oklch 字面量，也没有新增的 `text-[...]`、`tracking-[...]`、`leading-[...]` 任意值（布局几何除外，见项目 CLAUDE.md）。
- 每个改动的颜色和字号能指向上游的具体来源（文件与行）。
