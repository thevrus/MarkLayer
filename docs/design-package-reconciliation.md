# 2026-11-11 Design DNA 交付包核对记录

参考包：`MarkLayer-Design-DNA-2026-11-11.zip`。原压缩包保持原样，本记录是项目内的纠偏清单；设计规范以 [v1.0](design-standard-v1.md) 为准。核对对象为 `d3d62e8` 附近的源码静态定义，未做 Figma 导入或运行界面的逐项视觉验收。

| 项目 | 核对结果 / 处置 |
| --- | --- |
| 交付格式 | 原包是 Markdown、JSON、HTML 和 PNG，不含 `.fig`；是参考材料，不满足 v1.0 可编辑 Figma 主交付要求。 |
| 主按钮与紫色 | 原包 DNA 同时将紫色称为主提交按钮用途，交接文档又采用中性按钮。共享 token 注释提及紫色用于提交，但 `--color-ml-btn` / `--color-ml-btn-fg` 定义中性色，具体组件可能不同；v1 以对应实际组件与语义 token 为准，不把紫色实底或中性实底宣布为所有按钮的现状。新设计偏离时列出确认。 |
| 选中态 | 工具栏 `ctlOn` 是反色；`geist.segment` 选中则是凸起表面。不能把反色推广到所有控件。 |
| 焦点色 | `geist.ts` 控件焦点用 `--ds-focus-color`，Web 亮 / 暗分别为 `#0070f7` / `#50a8ff`；不能将包中紫色焦点描述推广到所有控件。 |
| 间距 | 原文称均为 4px 倍数，却列出 6、10、14px；现有实现包含半步。沿用实际 token 与组件，不设不成立的倍数规则。 |
| 字体 | Web 样式声明 Geist 字体资源，扩展字体栈优先系统字体；原包“仅系统字体栈、无自托管”不适用于 Web。Figma 字体可用性、授权与缺字回退待确认。 |
| 圆角公式 | 工具栏 12−4=8 有源码依据；不能无条件推广到所有面板，包内 12px 面板减 16px 内边距也不成立。 |
| 推测值 | 图钉悬停 1.1、评论卡宽度、拖拽阈值、吸附边距及断点等未从本次取证确认；不作为固定值。焦点 offset 在代码中已核实，不再称作推测。 |
| 新增设计 | Task Card、Model Picker、Collaboration Wizard 等是原包提出的新设计；不能据此声称已实现或已批准。 |
| Variables | 原包给出手动与插件导入建议，但没有可编辑 Figma 文件，也未实测 JSON 导入兼容性、色彩转换或变量绑定。须实际导入、检查后才能验收。 |
| 玻璃和暗色 | Web 与扩展在浅色玻璃背景上存在不同定义；模糊参数及每个页面的实际效果待逐项核实，避免将某一个值推广到全项目。 |

未来设计师应在交付模板中说明上述待确认项，实际建立和交付可编辑 Figma 后再逐项验收。
