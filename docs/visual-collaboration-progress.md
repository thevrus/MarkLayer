同一隔离网页、900×700 视口，使用项目内缩放控件从 90% 切回 100% 后，两个标记框屏幕宽度从约 25.2 变为 28 CSS 像素。此记录只覆盖项目内缩放；自动化 Ctrl++ 未改变浏览器缩放读数，因此不能记作浏览器缩放测试。
